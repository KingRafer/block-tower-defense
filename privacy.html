Kebijakan Privasi

Terakhir diperbarui: 26 November 2026

Block Tower Defense ("kami") adalah game browser yang dapat dimainkan di blocktowerdefense.vercel.app. Halaman ini menjelaskan data apa yang kami kumpulkan dan bagaimana data tersebut digunakan.

Data yang kami kumpulkan

  • Data akun Google (jika kamu masuk dengan Google): ID akun Google, nama, alamat email, dan foto profil. Kami tidak menerima password Google kamu.
  • Data permainan: progres, unit, mata uang dalam game, statistik, pencapaian, skor, daftar teman, riwayat trading, dan pesan chat dalam room.
  • Data transaksi top up: nomor pesanan, paket, nominal, dan status pembayaran. Data pembayaran (kartu, e-wallet, rekening) diproses oleh Midtrans dan tidak disimpan oleh kami.
  • Data teknis: data yang diperlukan untuk menyambungkan pemain saat bermain bersama (mabar), seperti pesan koneksi sementara.

Penggunaan data

  • Membuat dan mengelola akun serta menyimpan progres di cloud.
  • Menampilkan nama dan foto profil kepada pemain lain (teman, lobby, papan skor).
  • Menjalankan fitur teman, mabar, trading, dan papan skor global.
  • Memproses top up dan mengirim item yang dibeli.

Kami tidak menjual data pribadi dan tidak menggunakannya untuk iklan.

Penyimpanan & pihak ketiga

Data disimpan di MongoDB Atlas dan server dijalankan di Vercel. Login menggunakan Google Identity Services, pembayaran menggunakan Midtrans. Pesan koneksi mabar dihapus otomatis dalam beberapa menit.

Penghapusan data

Kamu dapat meminta penghapusan akun beserta seluruh datanya dengan menghubungi kami melalui email di bawah. Data di perangkat (localStorage) dapat dihapus lewat menu Pengaturan → Reset di dalam game.

Anak-anak

Pengguna di bawah 13 tahun harus menggunakan game ini dengan izin orang tua/wali, terutama untuk fitur top up.

Kontak

Pertanyaan tentang privasi: GitHub Issues atau email pengelola game yang tercantum di halaman persetujuan login Google.
